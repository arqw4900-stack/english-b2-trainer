# English B2 Trainer

Тренажёр английского уровня B2 в одном HTML-файле. Работает как артефакт Claude (с синхронизацией прогресса между устройствами) и как обычная страница в браузере.

**Открыть тренажёр:** https://arqw4900-stack.github.io/english-b2-trainer/ (работает на телефоне и компьютере, без регистрации; прогресс хранится в браузере)

Версия в Claude с синхронизацией между устройствами (приватная): https://claude.ai/artifact/SW9ZzSpPHhpy5FjUdw1SiS

## Что внутри

- **Слова** — 2455 слов и выражений в 12 темах (по 200–214 в каждой), включая тему **«Разговорный английский»**: сленг, разговорные слова, фразы для общения и идиомы (*no worries, skint, a piece of cake, hang in there*). Интервальные повторения (1 → 2 → 4 → 7 → 14 … дней), три типа карточек: выбор перевода, перевод на английский, ввод с клавиатуры. Синонимы не считаются ошибкой.
- **Времена** — 12 времён + be going to: формулы, маркеры, примеры и 130 упражнений с объяснением «Почему» к каждому ответу.
- **Чтение** — 20 коротких историй (B1–B2), одна из них целиком на разговорном английском: перевод слов и выражений по нажатию и 3 вопроса на понимание.
- **Прогресс** — серия дней, график ответов, прогноз повторений, экспорт и импорт прогресса в JSON.

## Как запустить

- **В браузере:** открыть ссылку на GitHub Pages выше. Прогресс хранится в этом браузере; переносить его можно через «Настройки → Резервная копия».
- **Как приложение на телефоне:** открыть ссылку на GitHub Pages → на iPhone «Поделиться» → «На экран „Домой“», на Android меню браузера → «Установить приложение» (или кнопка в «Настройках»). После первого открытия тренажёр работает без интернета: это делают `manifest.webmanifest`, `sw.js` и иконки `icon-*.png`. В артефакте Claude они не используются.
- **В Claude:** открыть ссылку на артефакт (нужен доступ к нему). Прогресс хранится в аккаунте и одинаков на телефоне и компьютере.
- **Локально:** открыть `index.html` в браузере. Прогресс хранится в `localStorage` этого браузера; переносить его можно через «Настройки → Резервная копия».

## Как устроен файл

Всё в `index.html`: стили, данные и логика, без сборки и библиотек (только Google Fonts).

| Часть | Где искать |
|---|---|
| Словарь | `const THEMES` — `[en, ipa, ru, пример]` по темам |
| Упражнения по временам | `const TENSES` → `ex`: `"предложение\|ответ\|неверный\|неверный\|неверный#idВремени#объяснение"` (id пустой, если ответ относится к самому времени) |
| Истории | `const STORIES` — абзацы, `gloss` (слово → перевод), `q` (вопрос, верный, неверные) |
| Состояние | `S = {w, log, tn, rd, set}`: слова, ответы по дням, лучшие результаты по временам, прочитанные истории, настройки |
| Повторения | `grade()`, `IV` (интервалы), `buildQueue()` |
| Синхронизация | `merge()` + `pushRemote()`: слияние по времени изменения, сброс через метку `rs` |
| Оформление | токены цветов в `:root` + тёмная тема через `prefers-color-scheme` и `[data-theme]` |

## Публикация в Claude

Артефакт объявляет возможности `db` (прогресс в `data/users/<id>/progress`), `user` (id пользователя) и `downloads` (экспорт файла). Обновлять — публикацией `index.html` с `url` артефакта.

## Заметки для следующих проектов

- В артефакте нельзя скачивать файлы через `<a download>` — нужен capability `downloads`; локально работает обычная загрузка. Код поддерживает оба случая.
- Claude ставит `data-theme` на `<html>`, поэтому не использовать атрибут `data-theme` для своих элементов.
- `alert/confirm/prompt` в артефакте не работают — подтверждения делать прямо на странице.
- Цвета только через токены, обе темы задавать явно; анимации — внутри `prefers-reduced-motion: no-preference`.
- Прогресс между устройствами сливать по времени изменения каждой записи, а не перезаписывать целиком.
