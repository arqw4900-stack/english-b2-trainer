# English B2 Trainer

Тренажёр английского уровня B2 в одном HTML-файле. Работает как артефакт Claude (с синхронизацией прогресса между устройствами) и как обычная страница в браузере.

**Открыть тренажёр:** https://arqw4900-stack.github.io/english-b2-trainer/ (работает на телефоне и компьютере, без регистрации; прогресс хранится в браузере)

Версия в Claude с синхронизацией между устройствами (приватная): https://claude.ai/artifact/SW9ZzSpPHhpy5FjUdw1SiS

## Что внутри

- **Слова** — 2819 слов и выражений в 14 темах, включая тему **«Разговорный английский»**: сленг, разговорные слова, фразы для общения и идиомы (*no worries, skint, a piece of cake, hang in there*). Интервальные повторения (1 → 2 → 4 → 7 → 14 … дней), три типа карточек: выбор перевода, перевод на английский, ввод с клавиатуры. Синонимы не считаются ошибкой.
- **Сочетания, фразовые глаголы, идиомы** — 167 коллокаций (не просто *decision = решение*, а *make a decision, reach a decision, make an informed decision, a tough decision*), 293 фразовых глагола и 110 идиом и живых выражений. В карточке «Допишите выражение» нужно вписать недостающее слово или частицу; на карточке слова показываются его сочетания.
- **Умные повторения** — интервал подстраивается под каждое слово: учитываются ошибки, подсказки, опечатки, время ответа и «лёгкость» конкретной карточки. Для каждого слова отдельно видно: **узнаю** (выбор перевода) → **вспоминаю** (ввод с клавиатуры) → **использую** (слово в нужной форме в предложении). Слова, которые постоянно забываются, попадают в «Трудные слова» и возвращаются чаще.
- **Мой словарь** — свои слова с переводом и примером; учатся как обычные карточки и в ежедневном занятии идут первыми. В версии в Claude перевод и пример может подсказать Claude.
- **Практика** — задания, где ответ пишете сами: перевод с русского, исправление ошибок, перефразирование (трансформации как на экзамене B2), смена регистра, пропуски без вариантов, словообразование, продолжение мысли, своё предложение с выражением, короткое мнение (147 заданий). В Claude ответ, не совпавший с эталоном, проверяет Claude и показывает ошибки; на GitHub Pages — сравнение с эталоном и самопроверка.
- **Грамматика B2** — 15 тем: модальные глаголы (долг и догадки), условные предложения, I wish, пассив, косвенная речь, придаточные определительные, герундий и инфинитив, причастные обороты, used to / be used to, инверсия, выделение (It is… that, What…), артикли, предлоги, связки. Правило, таблица, примеры и 151 упражнение с вводом ответа и объяснением.
- **Времена** — 12 времён + be going to: формулы, маркеры, примеры и 130 упражнений с объяснением «Почему» к каждому ответу. Теперь это часть раздела «Практика».
- **Письмо** — 14 заданий B2: жалоба, запрос информации, сопроводительное письмо, извинение, неформальные письма, эссе-мнение, эссе «за и против», рецензии, статья, отчёт, письмо в газету. Порядок: задание → свой текст → проверка → исправления → переписывание (текст засчитывается только после переписывания). В Claude текст проверяет Claude: грамматика, лексика и сочетаемость, построение предложений, связность и связки, регистр — ошибки прямо в тексте, оценка по пяти критериям, улучшенный вариант и советы. Без Claude — автоматические проверки (объём, формулы письма, сокращения, разговорные слова, связки, повторы), самопроверка по образцу и готовый запрос для проверки в чате с ИИ.
- **Чтение** — 20 коротких историй (B1–B2), одна из них целиком на разговорном английском: перевод слов и выражений по нажатию и 3 вопроса на понимание.
- **Коала Коко** — живёт на главной: довольна и прыгает с листиком эвкалипта, если сегодня сделан хотя бы один урок (законченное занятие, тест по временам или история), ждёт, если урока ещё нет, грустит, если вчера пропустили, и плачет под тучкой после нескольких пропущенных дней. Говорит по-английски с переводом; под ней — неделя с отпечатками лап за дни с уроками.
- **Прогресс** — серия дней (считаются дни с уроком), уровни знания слов (узнаю / вспоминаю / использую), трудные слова, практика, грамматика, тексты, график ответов, прогноз повторений, экспорт и импорт прогресса в JSON.

## Как запустить

- **В браузере:** открыть ссылку на GitHub Pages выше. Прогресс хранится в этом браузере; переносить его можно через «Настройки → Резервная копия».
- **Как приложение на телефоне:** открыть ссылку на GitHub Pages → на iPhone «Поделиться» → «На экран „Домой“», на Android меню браузера → «Установить приложение» (или кнопка в «Настройках»). После первого открытия тренажёр работает без интернета: это делают `manifest.webmanifest`, `sw.js` и иконки `icon-*.png`. В артефакте Claude они не используются.
- **В Claude:** открыть ссылку на артефакт (нужен доступ к нему). Прогресс хранится в аккаунте и одинаков на телефоне и компьютере.
- **Локально:** открыть `index.html` в браузере. Прогресс хранится в `localStorage` этого браузера; переносить его можно через «Настройки → Резервная копия».

## Как устроен файл

Всё в `index.html`: стили, данные и логика, без библиотек (только Google Fonts). Новые разделы лежат в текстовых файлах `data/` и вставляются в `index.html` командой `python data/build.py` (она же проверяет повторы слов и формат заданий).

| Часть | Где искать |
|---|---|
| Словарь | `const THEMES` — `[en, ipa, ru, пример]` по темам |
| Новые темы слов | `data/words/*.txt` — `english \| русский \| пример`, `[слово]` — то, что вписывается в карточке; тема с именем существующей добавляет к ней слова |
| Грамматика B2 | `data/grammar.txt` — `rule:`, `table:`/`row:`, `e:` пример `;;` перевод, `tip:`, `q:` предложение с ___ `\|` ответ `\|\|` другой ответ `\|` почему |
| Практика | `data/practice.txt` — типы `tr fix para reg gap wf cont use op` |
| Письмо | `data/writing.txt` — `@ id \| вид \| группа \| регистр \| слов \| название \| по-русски`, `task:`, `ru:`, `pt:`, `ph:`, `m:` |
| Упражнения по временам | `const TENSES` → `ex`: `"предложение\|ответ\|неверный\|неверный\|неверный#idВремени#объяснение"` (id пустой, если ответ относится к самому времени) |
| Истории | `const STORIES` — абзацы, `gloss` (слово → перевод), `q` (вопрос, верный, неверные) |
| Состояние | `S = {w, log, tn, rd, gr, pr, wr, my, set}`: слова (ступень, интервал, ошибки, лёгкость, навыки), ответы по дням, лучшие результаты по временам, истории, грамматика, практика, тексты, свой словарь, настройки |
| Повторения | `grade()`, `quality()`, `interval()`, `kindFor()`, `IV` (базовые интервалы), `buildQueue()` |
| Синхронизация | `merge()` + `pushRemote()`: слияние по времени изменения, сброс через метку `rs` |
| Оформление | токены цветов в `:root` + тёмная тема через `prefers-color-scheme` и `[data-theme]` |

## Публикация в Claude

Артефакт объявляет возможности `db` (прогресс в `data/users/<id>/progress`), `user` (id пользователя), `downloads` (экспорт файла) и `sample` (проверка ответов и текстов через Claude). Обновлять — публикацией `index.html` с `url` артефакта.

## Заметки для следующих проектов

- В артефакте нельзя скачивать файлы через `<a download>` — нужен capability `downloads`; локально работает обычная загрузка. Код поддерживает оба случая.
- Claude ставит `data-theme` на `<html>`, поэтому не использовать атрибут `data-theme` для своих элементов.
- `alert/confirm/prompt` в артефакте не работают — подтверждения делать прямо на странице.
- Цвета только через токены, обе темы задавать явно; анимации — внутри `prefers-reduced-motion: no-preference`.
- Прогресс между устройствами сливать по времени изменения каждой записи, а не перезаписывать целиком.
